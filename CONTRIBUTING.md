# Contributing

Start with an issue and observable acceptance criteria. Use Node >=24.9, run `npm ci`, then `npm run check`. Keep changes small and document what was tested with mocks versus real accounts.

Do not include runtime directories, credentials, cookies, raw account messages, or copied third-party PDFs. Keep public documentation portable, using relative project paths instead of personal machine paths.

The project currently has no distribution license selected. Public visibility alone does not grant a broad reuse license; a license decision will be recorded before packaging a release.
